Install in Stremio

How to Install:

  1. Click Install in Stremio to open Stremio and install automatically.
  2. Or, click the copy icon, open Stremio, navigate to Add-ons, paste the link into the search box, and click Install.
Browser/Web App Note: Stremio Web App (web.stremio.com) blocks local HTTP connections due to browser security. For local testing, copy the link and install it directly in the Stremio Desktop App.
